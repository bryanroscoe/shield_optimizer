# Thomson T32RTL6000 (manufacturer SCBC, Realtek platform), Android TV 9 (API 28), 1.5 GB
# RAM, 1280x720 output. Firmware PTT1.210114.001 build 337 (2021-04-25), security patch 2021-03-05.
# The OS itself reports model/device strings "ATV R1"/"R1" on this TV — same hardware:
# fingerprint THOMSON/THOMSON/R1:9/PTT1.210114.001/337:user/release-keys
#
# Apply:   TV_HOST=<tv ip> tools/disable.sh examples/thomson-t32rtl6000/debloat.txt
# Undo:    TV_HOST=<tv ip> tools/restore.sh examples/thomson-t32rtl6000/debloat.txt
# Everything is DISABLED, not uninstalled. Comment out any line you want to keep.
#
# Same platform family as examples/sanyo-atv-r2/ (SCBC, PTT1.x firmware branch): the SANYO
# list cross-checks several decisions here (the GDPR consent agent, and FastScreen being a
# FastCast Miracast receiver rather than a launcher on this family).
#
# Stock launcher: com.google.android.tvlauncher (restore.sh / build-and-install.sh defaults work).
# Live TV app: com.android.tv with the Realtek tuner stack (com.realtek.dtv and friends) —
#   the tuner must stay enabled or live channels disappear.
# TvProvider quirk: on this firmware the system TvProvider stays empty — the vendor tuner
#   keeps channels and EPG in its own store, so launcher channel rows are dormant until the
#   provider fills (e.g. after a firmware update).
# Kept on purpose: GMS / Play / WebView / keyboard, the tuner stack above, remote/Bluetooth
#   (com.apps.smartkey, bluetoothremote, fivekey, virtualkey, autopair),
#   com.creative.fastscreen.tv (FastCast Miracast receiver on this family — NOT a FastScreen
#   ad app, do not disable it as one), and streaming apps left to taste.

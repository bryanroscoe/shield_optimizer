# Hisense E5Q Pro (internal model "VIDAA_TV", MediaTek MT9653), VIDAA on Android 11, firmware 02.02.70.01
# Security patch 2022-09-05. China-market set: a VIDAA/Android hybrid with no Google TV launcher,
# so the stock home is com.jamdeo.tv.vod and the tuner app is com.jamdeo.tv.livetv; both are left
# alone here. The VIDAA UI keeps working; this list only removes the ad, telemetry, push and
# preloaded-content layer on top of it.
# Same VIDAA_TV / MT9653 / 02.02.70.01 build as examples/vidda-mt9653/, which goes further (it also
# swaps the launcher); this list is the conservative subset that keeps the stock home.
#
# Apply:   TV_HOST=<tv ip> tools/disable.sh examples/hisense-e5q-pro/debloat.txt
# Undo:    TV_HOST=<tv ip> tools/restore.sh examples/hisense-e5q-pro/debloat.txt
# Everything is DISABLED, not uninstalled. Comment out any line you want to keep.
#
# Applied and lived with for a few days: no crashes, normal boot, and the inputs / HDMI-CEC and the
# Sogou TV keyboard kept working. OTA (com.jamdeo.updateservice, com.hisense.usbupgrade,
# com.hisense.playerupdate) is left enabled on purpose so firmware updates still arrive.
#
# Also useful on this firmware, as an extra ad-block flag (not a package):
#   settings put global com.hisense.service.ad_block 1

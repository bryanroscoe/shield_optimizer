# Sony BRAVIA KD-65X9300D (2016, SVP-DTV15 "BRAVIA 4K 2015" platform, MediaTek), Asia-Pacific firmware
# Android TV 8.0, build OPR2.170623.027.S16 (6.827), 32-bit ARM (armeabi-v7a), 1.5 GB RAM
#
# Apply:   TV_HOST=<tv ip> tools/disable.sh examples/sony-kd-65x9300d/debloat.txt
# Undo:    TV_HOST=<tv ip> tools/restore.sh examples/sony-kd-65x9300d/debloat.txt
# Everything is DISABLED, not uninstalled. Comment out any line you want to keep.
#
# Stock launcher: com.google.android.tvlauncher (restore.sh's default). The only other HOME handler is
# com.android.tv.settings/.FallbackHome. setupwraith has no HOME activity on this firmware, and the
# saved Wi-Fi belongs to android.uid.system, so it is left alone.
# Live TV / input app: com.sony.dtv.tvx. Keep it: it also plays every HDMI input.
# Keep: com.sony.dtv.tvinput.*, tvplayer*, braviasync* (HDMI-CEC), remotepairing, remotecontrolsettings,
# uinputservice, imeproxy, ime.chww (the active keyboard), settingsprovider, netflixmanager (Netflix
# button), duid.generator, enclave.service, systemupdate, timers, all com.mediatek.* and mtktvapi.agent.
# Left alone on purpose: the rest of com.sony.dtv.b2b.* (hotel/pro mode plumbing), webapi.core and
# remoteaccess (Sony IP control), privacypolicy, com.google.android.leanbacklauncher (no HOME activity).
# Already disabled at the factory/by owner: com.sony.dtv.kenhchonloc, com.crackle.androidtv,
# com.sony.dtv.notifybravia, com.sony.dtv.tvcamera. Not in this list so restore.sh leaves them off.
# No Samba TV (tv.samba.ssm) on this firmware.
#
# Notes from this firmware:
# - build-and-install.sh hands Home over cleanly: com.google.android.tvlauncher is disabled last and
#   Home resolves to com.gathin.tvhome straight away.
# - Inputs works: com.sony.dtv.tvx handles the passthrough URIs; HDMI 1-4 (with CEC device names),
#   Video 1/2 and Live TV listed. Dock: Netflix, YouTube, Prime Video, com.sony.dtv.tvx; live_tv_package
#   com.sony.dtv.tvx; nothing hidden (the grid is Play Store, Timers, Programme guide, Screen mirroring).
# - Building on macOS with only a newer JDK: Gradle 8.9 needs JDK 17 (brew install openjdk@17) and the
#   android-34 platform (sdkmanager "platforms;android-34").
# - 1.5 GB RAM. Survives a reboot straight into the new launcher; no crashes logged after boot.

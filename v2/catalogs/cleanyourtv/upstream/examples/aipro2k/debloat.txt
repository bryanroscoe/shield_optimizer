# AiPro2K (Expressluck, device dongnae), Android TV 14, firmware UKN6.260116.085
# Same Changhong "AI PONT" family as examples/rca-ai-pont and examples/chiq-gtvu65, but vendor apps are
# Expressluck / CVTE instead of Homwee. 1 GB RAM (MemTotal about 930 MB), UI 1280x720 at 213 dpi.
# Stock launcher: com.google.android.apps.tv.launcherx (pass it as STOCK_LAUNCHER)
#
# Tested on one set (the same day it was applied, not a multi-day soak): after applying the list, installing
# launcher/ and rebooting, Home opens the new launcher, HDMI 1-3 switch from the dock and the Inputs menu,
# Netflix launches, the microphone button and the phone remote work, and logcat shows no FATAL or ANR.
# The IP did not change across the reboot, but a DHCP reservation is still a good idea.
#
# Apply:   TV_HOST=<tv ip> tools/disable.sh examples/aipro2k/debloat.txt
# Undo:    TV_HOST=<tv ip> tools/restore.sh examples/aipro2k/debloat.txt com.google.android.apps.tv.launcherx
# Everything is DISABLED, not uninstalled. Comment out any line you want to keep.
#
# Already disabled from the factory (do not re-enable them on restore): com.cltv.hybrid,
# com.google.android.marvin.talkback.
#
# Kept on purpose, do not disable:
# - com.mediatek.tv.service, com.mediatek.tvinput, com.mediatek.autopair: remote control and HDMI.
# - com.mediatek.wwtv.tvcenter(.plus), com.mediatek.wwtv.setupwizard: Live TV and the Inputs menu.
# - com.google.android.apps.mediashell: Chromecast.
# - com.google.android.katniss: microphone button and voice search.
# - com.google.android.tv.remote.service: controlling the TV from the phone.
# - com.epl.hotkey (HotKeyDispatcher, runs as system, has INJECT_EVENTS): probably handles the remote's
#   Netflix / YouTube / Prime / Live TV buttons. Inferred from its permissions, not tested.
# - Factory packages (com.cvte.tv.at, com.at.factory.*, com.express.at.factory.factorymanager,
#   com.expressluck.facmenu, mediatek.factorymenu.ui).
# - com.google.android.tv.dfuservice, googletvremotepairer, com.google.android.tv.inputplayer.
#
# The apex packages below (adservices, ondevicepersonalization, federatedcompute) accepted `pm disable-user`.
#
# Quirks on this firmware:
# - With launcherx disabled, Home falls to com.google.android.tungsten.setupwraith/.RecoveryActivity, so
#   launcher/build-and-install rolled back until setupwraith was disabled too. List both, last.
# - com.google.android.gms shows a Google sign-in dialog when an app is started from the command line; it
#   is Play Services, not something on this list.

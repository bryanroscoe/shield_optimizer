# Everything is DISABLED, not uninstalled. Comment out any line you want to keep.
#
# Stock launcher: com.google.android.apps.tv.launcherx (pass it as STOCK_LAUNCHER / to restore.sh).
# No separate Live TV app on this set: HDMI inputs come from TvInputManager, so leave live_tv_package empty.
# Keep the com.sony.dtv.tvinput.* HDMI services, com.sony.dtv.tvapi, com.sony.dtv.sonysystemservice
# and the Sony settings apps: they drive HDMI, picture settings and the remote.
#
# Quirks on this firmware, all checked on the TV:
# - Network ADB: pair once with Wireless debugging (`adb pair <ip>:<port> <code>`, then
#   `adb connect` to the port `adb mdns services` shows), then `adb tcpip 5555` for tools/tv.py.
#   Port 5555 closes again after a reboot.
# - com.google.android.tungsten.setupwraith claims HOME with priority 1 (RecoveryActivity); disable it
#   before launcherx or Home can land on it.
# - The default screensaver is com.sony.dtv.livingfit; with it disabled the TV has none until you
#   pick another (the launcher's Clock: `settings put secure screensaver_components
#   com.gathin.tvhome/.ClockDream`).
# - YouTube Music for TV (com.google.android.youtube.tvmusic) ends its media session when you leave it,
#   so music stops on Home; SoundCloud keeps playing.
#
# Most of this list was disabled by the owner before the launcher went on and has been lived with;
# the Sony agents, help and Play extras marked (new) were added on 19 October 2026. If something
# breaks, re-enable it with `pm enable <package>` and please report it.

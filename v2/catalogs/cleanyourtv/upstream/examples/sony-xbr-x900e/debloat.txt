# Sony BRAVIA XBR-65X900E (2017, BRAVIA_ATV2, MediaTek), US/Canada firmware
# Android TV 9, build PTT1.190515.001.S54
#
# Apply:   TV_HOST=<tv ip> tools/disable.sh examples/sony-xbr-x900e/debloat.txt
# Undo:    TV_HOST=<tv ip> tools/restore.sh examples/sony-xbr-x900e/debloat.txt
# Everything is DISABLED, not uninstalled. Comment out any line you want to keep.
#
# Stock launcher: com.google.android.tvlauncher (restore.sh's default).
# Live TV / input app: com.sony.dtv.tvx. Keep it: it also plays every HDMI input.
# Keep: com.sony.dtv.tvinput.*, braviasync* (HDMI-CEC), remotepairing, rcpowerkey, uinputservice,
# imeproxy, sonysystemservice, settingsprovider, all com.mediatek.* and mtktvapi.agent, timers (sleep timer).
# Left alone on purpose: the rest of com.sony.dtv.b2b.* (hotel/pro mode plumbing), webapi.core and
# remoteaccess (Sony IP control, possibly used by Alexa control).
# Already disabled at the factory/by owner: com.sony.rvu, actionmenu.plugin.harmony, Vudu, Crackle,
# com.google.android.inputmethod.latin. Not in this list so restore.sh leaves them off.
#
# Notes from this firmware:
# - The stock launcher's HOME filter has priority 2, so `cmd package set-home-activity` reports Success
#   but Home keeps opening it until com.google.android.tvlauncher is disabled (build-and-install.sh
#   does this last). Launch com.gathin.tvhome/.MainActivity with `am start -n` to check it first.
# - Inputs works: com.sony.dtv.tvx handles the passthrough channel URIs, HDMI 1-4 and Video 1/2 listed.
#   Hide com.sony.dtv.tvx and com.sony.dtv.tvxlauncher.programguide in config.xml; set
#   live_tv_package to com.sony.dtv.tvx if you use an antenna.
# - 2 GB RAM. Survives a reboot straight into the new launcher.

# Xiaomi TV EA Pro 55" (MiTV-MTEQ0, codename baymax; sold as L55MA-EP), China-market firmware 23.6.26.4028,
# Android 10 (SDK 29, QQ2A.200305.004.A1), MediaTek/MStar, 3840x2160 panel (Android reports a 1080p UI mode).
# Stock launcher: com.mitv.tvhome (HOME activity .MainActivityUserMode). Live TV / sources: com.xiaomi.mitv.tvplayer.
#
# Apply:   TV_HOST=<tv ip> tools/disable.sh examples/xiaomi-mitv-mteq0/debloat.txt
# Undo:    TV_HOST=<tv ip> tools/restore.sh examples/xiaomi-mitv-mteq0/debloat.txt com.mitv.tvhome
# Everything is DISABLED, not uninstalled. Comment out any line you want to keep.
# Used for a day with two reboots and several standby cycles; nothing broke that is not noted here.
#
# Notes from this firmware (details in docs/devices/xiaomi-mitv-mteq0-baymax.md):
# - Home: the framework only accepts system apps or allowlisted package names as HOME, like the
#   MiTV-AETP0. The opt-in build -PlauncherApplicationId=com.ts.launcher (docs/devices/xiaomi-mitv-aetp0-dofus.md)
#   was accepted here: HOME resolved to it, also after a reboot and after a force-stop like the one
#   standby does. With the standard com.gathin.tvhome ID, disabling com.mitv.tvhome leaves
#   FallbackHome (a black screen).
# - Network ADB closes at every boot: com.xiaomi.mitv.settings writes adb_enabled=0 a few seconds after
#   boot. Re-enable it under Settings > Account & Security > ADB debugging.
# - Standby (power key) force-stops every non-system app after 2 s (MitvPowerManagerService ->
#   killAllThirdApp) unless a cloud allowlist exempts it. Android then drops any accessibility service
#   of those apps, so do not rely on an accessibility helper on this set.
# - com.xiaomi.mitv.upgrade and com.mediatek.TimeMeasurementAgent are persistent: the firmware starts them
#   at boot even when disabled. Disabling still blocks their components; the processes stay.
# - Shell cannot disable single components, `pm hide` (no MANAGE_USERS) or `pm uninstall --user 0`
#   (DELETE_FAILED_INTERNAL_ERROR) on this firmware, so whole-package disables are the only tool.
# - Wi-Fi 5 GHz: the Wi-Fi country code comes from Settings.Global service_region and falls back to CN,
#   which hides 5 GHz networks on channels 100-144. `settings put global service_region <CC>` and a Wi-Fi
#   off/on fixes it.
# - Xiaomi's package installer has no CONFIRM_INSTALL screen: stores that install split APKs through a
#   PackageInstaller session (Aptoide) hang at 80%. Stores using ACTION_VIEW (single APKs) work.
# - No Google services: the official YouTube TV app refuses to run; SmartTube works.
# - Privacy toggles worth flipping as well: settings put secure allow_oaid_used 0 (OAID ad ID),
#   settings put global individual_privacy_enabled 0 (personalised recommendations).

# Xiaomi MiTV-AXSO2 (codename dangalUHD, Amlogic/droidlogic, 2 GB RAM), Android TV 9 (SDK 28), firmware PI.6432.
# Same "dangal" board family as examples/xiaomi-mitv-axso0. India unit.
# Live TV app: com.android.tv (set it as live_tv_package and hide it in launcher config.xml).
# Stock launcher: com.google.android.tvlauncher (the default, disabled by build-and-install.sh).
#
# Apply:   TV_HOST=<tv ip> tools/disable.sh examples/xiaomi-mitv-axso2/debloat.txt
# Undo:    TV_HOST=<tv ip> tools/restore.sh examples/xiaomi-mitv-axso2/debloat.txt
# Everything is DISABLED, not uninstalled. Comment out any line you want to keep.
#
# Notes from this firmware:
# - USB debugging alone opens network ADB on port 5555; the stock adb binary worked from macOS here.
# - Default IME is already Gboard, so the Mi TV 4A missing-keyboard quirk doesn't apply.
# - Everything below stays disabled after `adb reboot`.
# - The remote's PatchWall button does nothing once com.mitv.tvhome.atv is disabled.
# - Google sign-in: tvlauncher's notification panel gets its list from com.google.android.tvrecommendations.
#   With both disabled, Play Services' "Sign-in required" notice has nowhere to show, and Play Store only says
#   "Authentication is required". To sign in again: `pm enable` both, open
#   com.google.android.tvlauncher/.notifications.NotificationsSidePanelActivity, select the notice, enter the
#   password, then disable both again. If the password page comes back after OK, press Back: the sign-in has
#   usually worked already.
# - Storage is tight: 4.4 GB /data with about 600 MB free. A Play Services update took about 300 MB right after
#   sign-in and Play installs then failed with error 1008; `pm trim-caches 64G` freed about 400 MB.
# - com.xiaomitv.sonyliv and com.zee5.xiaomiTV are old partner copies (2021-2023) with no launcher entry;
#   the Play Store apps com.sonyliv and com.graymatrix.did stay.

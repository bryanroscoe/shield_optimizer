# Apply:   TV_HOST=<tv ip> tools/disable.sh examples/artel-cvte-mt5863/debloat.txt
# Undo:    TV_HOST=<tv ip> tools/restore.sh examples/artel-cvte-mt5863/debloat.txt
# Everything is DISABLED, not uninstalled. Comment out any line you want to keep.
#
# Getting ADB on this firmware:
# - There are no Developer options and no stock Android Settings app.
# - ADB is "Debug > ADB Enable" in the full CVTE factory menu. Contrast + 9735 on the remote opens only a
#   short factory menu without it. The full menu opens by starting the exported service
#   com.cvte.fac.menu/.app.TvMenuWindowManagerService with the extra
#   com.cvte.fac.menu.commmand=com.cvte.fac.menu.commmand.factory_menu (three m's, as shipped).
# - The "Allow USB debugging" prompt appears only after a reboot.
# - ADB comes back on at every boot (persist.sys.usb.config=mtp,adb).
#
# DO NOT DISABLE com.talents.huanclientauth. With it disabled the boot never completes. It was recovered
# by re-enabling the package over ADB.
#
# The firmware re-enables these on every boot, so disabling them has no effect and they are not listed:
# com.cvte.tv.systemupgrade, com.tcl.update, cn.tcl.odm.android.vstoresubclient (Zeasn store),
# com.tcl.sticker, com.example.user.myapplication (FallbackHome). Hide them in the launcher's hidden_apps instead.
#
# The channel list was lost once during a boot that hung; Auto search in the TV's own menu restored it.

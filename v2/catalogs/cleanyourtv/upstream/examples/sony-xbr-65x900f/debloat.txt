# Same Android 9 firmware build as examples/sony-xbr-x900e and sony-bravia-4k-gb (ATV2), one platform
# generation newer (ATV3, MT5891). Package set is the same apart from the ATV3 panel/HDMI services.

# Live TV / input app: com.sony.dtv.tvx. Keep it: it also plays every HDMI input and the ATSC tuner.

# imeproxy, sonysystemservice, settingsprovider, all com.mediatek.* and mtktvapi.agent, timers.
# Already off on this TV before the list (owner or factory): tv.samba.ssm and com.sony.dtv.promos (both
# listed below anyway), com.sony.rvu, actionmenu.plugin.harmony, Vudu, Play Movies, Play Games.
#
# Notes from this firmware:
# - ADB: Developer options > USB debugging opens port 5555 (Android 9: no Wireless debugging pairing);
#   the TV then shows the usual "Allow USB debugging?" prompt. Tick "Always allow".
# - The sponsored banner at the top of the stock home (Hulu, Apple TV+ promos) comes from
#   com.google.android.tvlauncher itself and survives disabling tvrecommendations; only replacing the
#   launcher removes it.
# - Sony Settings pages (About, Status) return an empty screencap; read them with `uiautomator dump`.
# - The retail model number is not in getprop or UPnP (both say "BRAVIA 4K GB ATV3"); read it off the
#   sticker or the Help app.
# - Launcher works. Same as the X900E: the stock launcher's HOME filter wins until
#   com.google.android.tvlauncher is disabled; disable it, then `cmd package set-home-activity
#   com.gathin.tvhome/.MainActivity`. Home key from inside apps returns to the new launcher.
# - Inputs works: HDMI 1-4 (HDMI 3/ARC), Video and Live TV listed via com.sony.dtv.tvx. This firmware
#   reports real per-port status ("No device" / "Connected"), not every port as connected.
#   config.xml: hidden_apps com.sony.dtv.tvx and com.sony.dtv.tvxlauncher.programguide,
#   live_tv_package com.sony.dtv.tvx.

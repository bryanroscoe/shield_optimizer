# Notes from this firmware:
# - Home: launcherx has priority 2 and the setup wizard's RecoveryActivity priority 1, so setupwraith is in
#   this list (batch 6); with it disabled, build-and-install.sh set Home on the first try and it survives
#   reboots. Re-enable it before a factory reset (restore.sh does).
# - /data is 4 GB and was 99% full with a handful of streaming apps: the first launcher install failed with
#   "Requested internal only, but not enough space". `tools/tv.py 'pm trim-caches 1G'` freed ~450 MB.
# - `svc power reboot` is killed on this firmware; use `adb reboot` (and check `uptime`).
# - A key remapper (Button Mapper) was sending Home to another launcher; turn its accessibility service off.
# - The Sony tab on the Google TV home stays as a label after sonytab is disabled; it only goes with launcherx.
# - Applied in batches on one evening with reboots and checks after each (Home, Settings, inputs, Media Player,
#   no crashes). Not yet lived with for weeks; if something breaks, `pm enable <package>` and please report it.

# TCL 65C725 (reports as "Smart TV Pro", device BeyondTV4), Android TV 11 (SDK 30),
# build RP1A.200622.001 release-keys. Turkey/EU retail unit.
# Likely a good starting point for other TCL Android TV 11 sets of the same C-series era.
#
# Apply:   TV_HOST=<tv ip> tools/disable.sh examples/tcl-65c725/debloat.txt
# Undo:    TV_HOST=<tv ip> tools/restore.sh examples/tcl-65c725/debloat.txt
# Everything is DISABLED, not uninstalled. Comment out any line you want to keep.
#
# Stock launcher: com.google.android.tvlauncher — the launcher/ in this repo replaces it, and the
# restore.sh / build-and-install.sh defaults are already correct for this TV (no arg needed).
# Live TV app: com.tcl.tvinput — kept (it also owns HDMI/antenna playback). Hide its tile in the
# launcher config if you like; the Inputs menu covers it.
#
# Applied and re-verified on a real unit on 2026-10-18: Wi-Fi stayed up and Home, the Inputs
# dropdown and app launches all worked after the full list.
#
# Known quirks on this firmware:
# - Android 11 package visibility: the launcher in this repo needs a <queries> block for
#   MAIN+LEANBACK_LAUNCHER intents or its app grid comes up empty (verified with that patch).
# - screencap writes an empty file while Live TV/HDMI is on screen. Press Home first.
# - com.tcl.tv is deliberately NOT disabled here: it also hosts HbbTV and the Eva voice plumbing.
#
# DO NOT DISABLE on TCL (load-bearing):

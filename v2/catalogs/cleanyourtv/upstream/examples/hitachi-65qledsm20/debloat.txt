# Fingerprint: Hitachi/MTCMSD6886EU_Hitachi/bangbae:11/RTO8.250915.001/14107831:user/release-keys
# Content recognition and FAST channels come from Anoki (tv.anoki.acr.controller, com.cltv.fast), like the
# CHiQ / RCA / BenQ "AI PONT" sets on the same platform.

# Apply:   TV_HOST=<tv ip> tools/disable.sh examples/hitachi-65qledsm20/debloat.txt
# Undo:    TV_HOST=<tv ip> tools/restore.sh examples/hitachi-65qledsm20/debloat.txt
# Everything is DISABLED, not uninstalled. Comment out any line you want to keep.
#
# Stock launcher: com.google.android.tvlauncher (the scripts' default); the only other HOME claimant is
# com.android.tv.settings, so the setup wizard does not take over. Live TV: com.mediatek.wwtv.tvcenter.
# TV inputs (com.mediatek.tvinput): HDMI 1-4 = HW4-HW7, AV = HW1 (composite), tuners = HW0, HW8.
#
# KEEP, even though the names look like bloat:
# - fusion.android.tv.demo ("MtcRetailDisplay"): handles the remote's Input button (TV_INPUT_BUTTON,
#   CONNECT_INPUT) and Bluetooth remote pairing (mtc.bluetooth.AddAccessoryActivity).
# - com.google.android.leanbacklauncher.partnercustomizer: provides the tvlauncher.widget provider that
#   com.mediatek.tv.service needs after a reboot (see examples/chiq-ai-pont).
# - com.mediatek.mtc.factory (GLOBAL_BUTTON and USB attach receivers), com.mediatek.testpq (applies
#   picture settings at boot), com.mediatek.network, com.airoha.btd (Bluetooth chip), com.mediatek.*.
# - There is no separate firmware-update package on this build.
#
# Notes from this TV (all verified with screenshots and a reboot):
# - Stock adb on macOS fails with "No route to host" (Local Network privacy); tools/tv.py works.
# - After a reboot com.mediatek.tv.service logs "Failed to find provider info for tv.anoki.acr.controller.support"
#   once or twice and carries on: same PID minutes later, no crash loop. Home stays the new launcher.
# - HDMI and Live TV screenshots fail (protected video layer). The Inputs menu switches through tvcenter's
#   TurnkeyUiMainActivity; the Input key keeps opening tvcenter's InputsPanelActivity.
# - Free RAM after boot: about 590 MB (about 320 MB on the stock home before debloating).

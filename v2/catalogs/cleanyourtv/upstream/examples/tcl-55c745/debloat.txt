# TCL 55C745 (2023), device G08, model "Smart TV Pro", product G08_4K_GB, MediaTek tcl9618, 2.4 GB RAM.
# Google TV, Android 14 (SDK 34), firmware UTT2.250416.001 AU02 - the same build as examples/tcl-q7c-google-tv
# and examples/tcl-85rm7l-google-tv. Set up on Ethernet; France/UK household (French and UK catch-up apps
# alongside Stremio and a third-party YouTube client).
#
# Tested on one set, 21 October 2026. Disabled by hand with `pm disable-user --user 0`, one call each, in five
# batches plus two follow-ups, with a screenshot after each batch. All 50 packages below survived two reboots.
# launcherx and setupwraith were disabled afterwards, once the new launcher was confirmed as Home. YouTube
# (via SmartTube), Live TV, the HDMI input list, the Source key QuickPanel, D-pad navigation and the physical
# remote's Home/Input buttons were all checked.
#
# Apply:   FORCE_SETUPWRAITH=1 TV_HOST=<tv ip> tools/disable.sh examples/tcl-55c745/debloat.txt
#          FORCE_SETUPWRAITH=1 only on Ethernet with no saved Wi-Fi: disable.sh otherwise skips setupwraith
#          because it cannot see a Wi-Fi owner. On Wi-Fi, check `dumpsys wifi | grep cname` first (README).
#          launcherx is skipped by disable.sh's Home guard until the new launcher is Home; see README for order.
# Undo:    TV_HOST=<tv ip> tools/restore.sh examples/tcl-55c745/debloat.txt com.google.android.apps.tv.launcherx
# Everything is DISABLED, not uninstalled. Comment out any line you want to keep.
#

# choice), com.google.android.apps.mediashell (Chromecast), com.google.android.tv.remote.service, Play Store
# and Play Services, all com.mediatek.* and com.dolby.* except AirPlay.

# TCL 85RM7L Google TV (device G08, model "Smart TV Pro", MediaTek tcl9618 / mt5896)
# Android 14 (Google TV), firmware UTT2.250416.001 AU02, product G08_4K_GB, security patch 2025-12-05.
# About 2.4 GB RAM. Same board and firmware build as examples/tcl-c755-google-tv; that list was the
# starting point. Debloat only: the stock Google TV launcher stays, so setupwraith stays too.
#
# Apply:   TV_HOST=<tv ip> tools/disable.sh examples/tcl-85rm7l-google-tv/debloat.txt
# Undo:    TV_HOST=<tv ip> tools/restore.sh examples/tcl-85rm7l-google-tv/debloat.txt com.google.android.apps.tv.launcherx
#          TV_HOST=<tv ip> tools/venv/bin/python -I tools/tv.py 'settings delete secure screensaver_components'
# Everything is DISABLED, not uninstalled. Comment out any line you want to keep.
#
# Kept on purpose: Chromecast (com.google.android.apps.mediashell), AirPlay (com.tcl.airplay2,
# com.mediatek.AirplayAPK, com.mediatek.airplaydaemon), Miracast (com.tcl.miracast), the game bar,
# the USB media player and gallery, Google Assistant (katniss) and com.google.android.tv.remote.service
# (it carries the remote's mic button), plus everything the C755 header lists as Keep.
# Firmware updates come from Google Play Services (SYSTEM_UPDATE_SETTINGS resolves to
# com.google.android.gms/.update.SystemUpdatePanoActivity), so disabling com.tcl.ttvs leaves them alone.
#
# Tested 2026-10-20 on a real unit, applied in five batches with screenshots between them: Home, YouTube,
# Live TV (com.tcl.tv/com.tcl.player.TVActivity), the Input key's source panel (com.tcl.suspension, AirPlay
# and TV tiles), the four HDMI inputs in tv_input, Chromecast advertised over mDNS, and the AirPlay,
# Miracast and Assistant processes all kept working, and all 22 packages stayed disabled after a reboot.
# A USB DAC powered from the TV's USB port kept its power with USB debugging on.
# The source panel's Apps row keeps showing TCL Channel and User Guide tiles, which no longer open.
#
# Known trade-off: com.tcl.ttvs is one package holding Samba TV ACR, TCL BI analytics, Alexa core AND
# the T-Cast server (TVSServerService, CastService). Disabling it stops T-Cast; com.tcl.magiconnectfree
# is left enabled but has nothing to talk to.

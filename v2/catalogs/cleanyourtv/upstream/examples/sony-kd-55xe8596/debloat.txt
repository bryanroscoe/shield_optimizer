# Sony BRAVIA KD-55XE8596 (2017, model string "BRAVIA 4K GB", product BRAVIA_ATV2_EU, MediaTek MT5891), UK
# Android TV 9 (API 28), firmware Sony/BRAVIA_ATV2_EU/BRAVIA_ATV2:9/PTT1.190515.001.S52/672101:user/release-keys,
# security patch 2022-01-05 (Sony has stopped updating it). 2 GB RAM, about 8 GB /data.
#
# Apply:   TV_HOST=<tv ip> tools/disable.sh examples/sony-kd-55xe8596/debloat.txt
# Undo:    TV_HOST=<tv ip> tools/restore.sh examples/sony-kd-55xe8596/debloat.txt
# Everything is DISABLED, not uninstalled. Comment out any line you want to keep.
#
# Same product and platform as examples/sony-bravia-4k-gb (that list is firmware S54; this one is the older S52
# build, on the UK retail model). The package set matches. The difference is in the choices: this owner
# kept Chromecast, mirroring, DLNA, USB media, the Assistant and the phone remote, and also disabled the
# hotel/pro-mode b2b packages, the old leanback launcher and the print spooler.
# Applied 2026-10-19 (most of the list) and 2026-10-20 (Samba TV, agents, feeds). Not lived with for days
# yet, and not yet checked across a reboot. Checked after every batch: Home, Netflix, Jellyfin, live TV
# and the HDMI inputs all still work, and there are no new crashes. Re-enable anything that breaks with `pm enable <package>`.
#
# Stock launcher: com.google.android.tvlauncher (restore.sh's default). Its HOME filter has priority 2,
# so `cmd package set-home-activity` reports Success but does nothing until it is disabled.
# com.google.android.leanbacklauncher is also installed, but it has no HOME activity here.
# Live TV / input app: com.sony.dtv.tvx. Keep it: it plays every HDMI input too. On this UK firmware Live
# TV hands over to YouView (com.sony.dtv.youview + com.sony.dtv.youview.servicehost, Freeview Play),
# which has no leanback entry of its own: launch com.sony.dtv.tvx, not youview. Keep both, and keep
# com.vewd.core.integration.dia (HbbTV / red button). Hide only its "Internet Browser" tile.
# Keep: com.sony.dtv.tvinput.*, braviasync* (HDMI-CEC), remotepairing, rcpowerkey, uinputservice,
# imeproxy, sonysystemservice, settingsprovider, all com.mediatek.* and mtktvapi.agent, timers,
# webapi.core and remoteaccess (Sony IP control, used by Home Assistant's Bravia TV integration).
#
# Notes from this firmware:
# - The launcher works: built from launcher/, installed with `adb install`, and Home switched by hand. Inputs
#   lists HDMI 2, HDMI 3/ARC, HDMI 4 and Live TV, with the input labels set in Sony's settings and the CEC
#   device name in place of the port name, and real per-port "Connected" / "No device" status. config.xml:
#   live_tv_package com.sony.dtv.tvx; put com.sony.dtv.tvx in dock_apps if you want a TV tile.
# - /data was down to 1.5 GB free, nearly all of it app caches. `pm trim-caches 8G` took it to 2.8 GB, so
#   run it before installing anything.
# - The `uiautomator dump` of a launcher with an animated wallpaper never finishes, so use screencaps there.

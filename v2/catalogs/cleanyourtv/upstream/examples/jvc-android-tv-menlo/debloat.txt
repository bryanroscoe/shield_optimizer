# - fusion.android.tv.demo: unlike the Cecotec list, it must stay. On this firmware it receives
#   com.mstar.android.intent.action.TV_INPUT_BUTTON (the remote's Input key), as on

# - com.mediatek.android.leanbacklauncher.partnercustomizer: crash-loops com.mediatek.tv.service

# - com.google.android.tungsten.setupwraith: may own the saved Wi-Fi network.
# - every com.mediatek.*, mediatek.factorymenu.ui, com.vestel.tv.service / keycontroller / backlight /
#   eib / rcupdater / websocketservice, com.vestel.overlay.*, com.dolby.android.audio.service.
# - Chromecast built-in (mediashell), Play Store, Play Services, Gboard, TTS.
#
# Status: disabled in two batches on one TV on 2026-10-20 (the last two lines after launcher/ took Home),
# then checked on the remote by the owner: new launcher as Home, Input key, HDMI input switching and
# Live TV all work. Hours of real use, not days: treat it as a starting point.
#
# Quirks on this firmware:
# - USB debugging alone opened port 5555 (no separate network-debugging switch, no restart needed).
# - screencap fails (prints its usage) to /sdcard and /data/local/tmp alike: no screenshots over ADB.
# - TalkBack (com.google.android.marvin.talkback) ships disabled; not listed, so restore leaves it off.
# - ro.adb.secure = 1: port 5555 still shows the "Allow" prompt.

# Panasonic TH-40HS550K (Skyworth-built, GS655, codename shibuya, MediaTek m5621), Android TV 11 (API 30), firmware RTO9.240708.002 (12195242)
# Vendor fingerprint skyworth/SW1_T/shibuya. armeabi-v7a, UI at 1280x720, about 0.9 GB RAM.
# Classic Android TV home, not Google TV: the stock launcher is com.google.android.tvlauncher.
#
# Stock launcher:  com.google.android.tvlauncher
# Live TV app:     com.mediatek.wwtv.tvcenter  (Live TV and the input panel; keep it)
# Never disable any com.mediatek.* package: they are the tuner, input and HDMI stack.
#
# Apply:   TV_HOST=<tv ip> tools/disable.sh examples/panasonic-th-40hs550k/debloat.txt
# Undo:    TV_HOST=<tv ip> tools/restore.sh examples/panasonic-th-40hs550k/debloat.txt
# Everything is DISABLED, not uninstalled. Comment out any line you want to keep.
#
# Disabled before this debloat, so not listed (restore.sh would turn it ON): com.google.android.marvin.talkback.
#
# Status: disabled in four batches on one TV on 2026-10-19, with a screenshot after each batch and remote-key
# checks of Home, Live TV, the input panel and HDMI detection. Nothing broke in that testing; the list had
# about a day of real use when submitted, so treat it as a starting point.
#
# Quirks on this firmware, all checked on the TV:
# - Only the stock launcher and Settings' FallbackHome claim HOME; setupwraith does not. A sideloaded launcher
#   installs and can be set as home with `cmd package set-home-activity`, no signature check.
# - Screenshots: `exec-out screencap -p` mixes "Init wrapper sys mutex" / "open mma dev failed" lines into the
#   PNG. Write to a file with `screencap -p /sdcard/s.png` and pull it. While Live TV or an HDMI input is on
#   screen the file comes back empty (protected video layer).
# - The TV powers on to the last source (Live TV or an HDMI port). TV Settings contains a "Power on behavior"
#   string but this firmware shows no menu for it.
# - HDMI-CEC devices appear as child TV inputs, so the input list can show "HDMI 1  PlayStation 5".
# - Disabling partnercustomizer (below) removes the Inputs and Wi-Fi icons from the stock launcher's top bar;
#   irrelevant once launcher/ is home. The stock launcher also keeps a Play Movies tile after
#   com.google.android.videos is disabled: it is a built-in shortcut, not the app.
# - About 0.9 GB of RAM: the low-memory killer ends background apps (Netflix included) quickly.

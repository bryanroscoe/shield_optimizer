# TCL 55Q10G Pro (China), device tcl_mt5879_cn / product tcl_mt5879_cn_db, MediaTek MT9952,
# Android 11 (SDK 30), build RQ3A.210705.001 / 2026012200 (2026-01-22), 3.5 GB RAM.
# 32-bit only: ro.product.cpu.abilist = armeabi-v7a,armeabi. No Google services — apps come from
# com.tcl.appmarket2 or a USB stick. Likely a starting point for other 2026 China MT5879 sets.
#
# Apply:   TV_HOST=<tv ip> tools/disable.sh examples/tcl-q10g-pro/debloat.txt
# Undo:    TV_HOST=<tv ip> tools/restore.sh examples/tcl-q10g-pro/debloat.txt com.tcl.cyberui
# Everything is DISABLED, not uninstalled. Comment out any line you want to keep.
#
# ADB, read this before anything else: there is no "Build number" tap seven times on this firmware
# and no ADB row in developer options. Settings → About this device (关于本机) → Device info (本机信息),
# then press UP DOWN LEFT RIGHT on the remote; the ADB toggle appears at the bottom. The sequence
# often has to be repeated two or three times before it fires — a single pass looks like it did
# nothing, so keep going instead of assuming the path is wrong. Once on, it stays on across
# reboots:
#   persist.adb.tcp.port=5555, persist.service.adb.enable=1.
#
# Stock launcher: com.tcl.cyberui — the only activity that resolves MAIN+HOME, so never disable it
# (no HOME handler means a black screen on boot). A third-party launcher cannot be installed here:
# the refusal is a package verification step, not a parse error (see tcl-ak30a5 for the older
# Android 9 variant). Any APK declaring android.intent.category.HOME fails with
# INSTALL_FAILED_VERIFICATION_FAILURE and logs:
#   OverseasAppConfig: Verifying begin
#   verifier: fetch signature info from: com.tcl.cyberui
#   verifier: signature does not match for tcl <pkg>, will not be installed!
# The gate is com.android.packageinstaller → verifier/InstallStrategyManager → LauncherStrategy,
# which allows a HOME package only if it is in that strategy's package list, or is signed with
# com.tcl.cyberui's key and carries <meta-data com.tcl.app.type="com.tcl.ui">. The list is TCL's
# InstallConfig, readable with `content query --uri content://com.tcl.providers.config/all`
# (project_id=InstallConfig) and not writable from the shell.
#
# Sideloading is blocked for everything else too, not just launchers. On this unit `adb install`,
# `pm install`, `pm install-commit` and launching the exported InstallStart activity by hand all
# end in INSTALL_FAILED_VERIFICATION_FAILURE — including an APK signed by TCL itself, and with
# `-i com.tcl.appmarket2` spoofing the store as installer. Apps arrive through the TCL app store
# (com.tcl.appmarket2) or a USB stick via 电视卫士. Don't spend an afternoon on adb install.
#
# Live TV app: com.tcl.tv — keep it, it owns DTV/HDMI playback and the remote's source key.
# Kept on purpose:
#   com.tcl.guard                 电视卫士; on this firmware the USB install path is the remaining
#                                 way to sideload, so keep it
#   com.tcl.appmarket2            TCL app store, the other install channel
#   com.sohu.inputmethod.sogou.tv the only input method; disable it and there is no keyboard at all
#   com.tcl.ui_mediaCenter        USB playback; the whole Media Center app goes with it
#   com.tcl.settings, com.tcl.systemserver, com.tcl.ttvs (holds DEVICE_ADMIN_ENABLED)
#
# Applied on a real unit and re-checked after a full reboot (`reboot`, not standby): Home, the
# source panel (HDMI 1-4 plus TV/AV/cast), Media Center, the app store, 电视卫士 and Settings all
# still worked, with no entries in the crash buffer and no ANRs. Memory available went from 1.97 GB
# to 2.24 GB. Voice and TCL account services are off by choice, noted per group below.
#
# Expected in logcat afterwards, harmless: `Unable to start service ... com.tcl.usercenter` about
# every 20 seconds. The bind fails immediately and starts no process.
#

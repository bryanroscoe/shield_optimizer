# Xiaomi MiTV-AXFR1 (codename rango, product dune; Amlogic/droidlogic, 1 GB RAM, India), Android TV 11 (SDK 30),
# firmware RTT0.210630.002.485 (Xiaomi/dune/rango:11/RTT0.210630.002/485), security patch 1 November 2025.
# Same firmware family as xiaomi-mitv-axso0 (ships android.autoinstalls.config.xioami.dangal).
# Live TV app: com.android.tv (also owns the input picker, .input.SelectInputActivity).
# Stock launcher: com.google.android.tvlauncher (the default, disabled by build-and-install.sh).
#
# Apply:   TV_HOST=<tv ip> tools/disable.sh examples/xiaomi-mitv-axfr1/debloat.txt
# Undo:    TV_HOST=<tv ip> tools/restore.sh examples/xiaomi-mitv-axfr1/debloat.txt
# Everything is DISABLED, not uninstalled. Comment out any line you want to keep.
#
# Notes from this firmware:
# - USB debugging alone opens port 5555; no wireless-debugging pairing needed.
# - Sideloading works (pm install over the shell), and a third-party HOME app is accepted without a
#   Xiaomi signature. setupwraith is installed but does not claim HOME here, so it can stay enabled.
# - PatchWall (com.mitv.tvhome.atv) also contains an InputSourcePopupActivity, but the Settings key opens
#   stock TV Settings and the Inputs panel is com.android.tv's, so PatchWall is safe to disable.
#   Settings, the Inputs panel (HDMI 1, HDMI 2, AV, TV) and HDMI switching were checked after each batch.
# - An injected KEYCODE_TV_INPUT is unhandled on this firmware; inputs are reached from Settings or the launcher.
# - Live TV with no channels tuned goes straight to a channel scan when opened (stock behaviour too).
# - Disabled state, the Home default and Private DNS all survive a reboot. The TV can come back on a
#   different IP after a reboot (DHCP), so re-check TV_HOST.
# - Default IME is already Gboard; the Baidu-keyboard quirk from the Mi TV 4A doesn't apply.

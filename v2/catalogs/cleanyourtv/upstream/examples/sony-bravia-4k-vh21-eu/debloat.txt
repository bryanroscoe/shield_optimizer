# Live TV / tuner app: com.sony.dtv.tvx. Keep the com.sony.dtv.tvinput.* services, tvapi, sonysystemservice,

# all arrive as keycode 196 (scancodes 485, 490, 491), so remapping one of them needs a scancode entry in
# app_keys (scan:490:<package>) with HOME_KEY_SERVICE=1; a keycode remap (or a keycode-only remapper app)
# takes all three. KEYCODE_SETTINGS does nothing once launcherx is off; HomeKeyService brings it back.
# KEYCODE_TV_INPUT opens Sony's own input overlay, so INPUT_KEY_SERVICE is not needed here.

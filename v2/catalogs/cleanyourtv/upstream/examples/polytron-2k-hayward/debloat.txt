# Polytron 2K Android TV (WLTV POLYTRON2K, device hayward; Hisense/CVTE board, MediaTek mt5867), Android TV 11,
# build RTMA.250416.094. About 930 MB of RAM, 1280x720 UI, hardware decoders up to 1080p, classic Android TV
# launcher (com.google.android.tvlauncher) plus com.google.android.tungsten.setupwraith, which also claims Home.
#
# Apply:   TV_HOST=<tv ip> tools/disable.sh examples/polytron-2k-hayward/debloat.txt
# Undo:    TV_HOST=<tv ip> tools/restore.sh examples/polytron-2k-hayward/debloat.txt
# Everything is DISABLED, not uninstalled; comment out any line you want to keep. (The tested set had
# these packages removed for user 0, with the same effect.) Kept on purpose: Live TV
# (com.mediatek.wwtv.tvcenter), the USB media player, the Play Store, Google Play services and
# com.android.providers.contacts. The installer disables tvlauncher once the new Home is in.
#
# ADB: USB debugging opens network ADB on port 5555 directly. The TV hops between the 2.4 GHz and 5 GHz
# networks of a dual-band router and gets a new IP each time; reserve one on the router.

# Known quirks on this firmware:
# - USB debugging opens port 5555 straight away; no Wireless debugging pairing needed.
# - KEEP com.google.android.tv.remote.service. Besides the phone remote it carries the Bluetooth remote's
#   mic: with it disabled the mic button does nothing at all (no key event, no voice UI). Re-enabling it
#   brings the mic back. It holds the android.app.role.SYSTEM_TELEVISION_REMOTE_SERVICE role.
# - The Wi-Fi network saved during first setup belongs to setupwraith (dumpsys wifi: OwnerUid = setupwraith's
#   uid). Forget and re-join it in Settings > Network & Internet before disabling setupwraith; afterwards it
#   shows cname=android.uid.system:1000. tools/disable.sh skips setupwraith until then.
# - setupwraith's RecoveryActivity claims Home (priority 1) and goes before launcherx, as on the Chromecast.
# - Voice search (Gemini / com.google.android.katniss) keeps working with launcherx disabled.
# - Remote buttons (/vendor/usr/keylayout/Vendor_0957_Product_0031.kl):
#     YouTube = KEYCODE_BUTTON_3 and Free TV = KEYCODE_FEATURED_APP_1, both routed to launcherx, so they do
#     nothing once it is disabled. Netflix = KEYCODE_BUTTON_4; the Disney+ and Paramount+ buttons send
#     BUTTON_9 / BUTTON_10. Those three go to com.droidlogic's GlobalKeyReceiver ("oneTouchPlay"), which opens
#     the app, and for a disabled or missing app logs "Cannot find intent" or opens its Play Store page.
#   InputKeyService (INPUT_KEY_SERVICE=1 launcher/build-and-install.sh) with app_keys remaps them, checked
#   with the physical remote, e.g. in a theme's config.json:
#     "app_keys": ["KEYCODE_BUTTON_3:org.smarttube.stable", "KEYCODE_BUTTON_4:com.stremio.one",
#                  "KEYCODE_FEATURED_APP_1:com.amarullz.androidtv.animetvjmto"]
# - Free TV / "Freeplay" lives inside launcherx and goes with it.
# - Google TV / Play Movies (com.google.android.videos) is not preinstalled on this box.
# - Disabling dreamx leaves no screensaver set (screensaver_components was null; the default was dreamx).
#   Point it at the launcher's clock: settings put secure screensaver_components com.gathin.tvhome/.ClockDream
# - Animation scales already ship at 0.5x on this build.
#

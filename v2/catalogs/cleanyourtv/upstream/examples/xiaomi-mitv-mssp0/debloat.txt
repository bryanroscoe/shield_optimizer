# Apply: TV_HOST=<tv ip> tools/disable.sh examples/xiaomi-mitv-mssp0/debloat.txt

# Owner choices and checks:
# - Assistant, Gallery and the Xiaomi media browser are disabled by owner choice.
#   Keep their packages enabled if you use those features.
# - Before disabling Backdrop, install the launcher and select its Clock screensaver:
#     TV_HOST=<tv ip> tools/tv.py 'settings put secure screensaver_components com.gathin.tvhome/.ClockDream'

#   rollback/reapply check on 2026-10-19; Gallery and the media browser were disabled later that day.

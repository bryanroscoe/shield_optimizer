# Bundled fonts

`material-symbols-rounded.woff2` is a modified subset of Material Symbols Rounded from the
Apache-2.0 `material-symbols` npm package (currently 0.45.5). It is generated from the original
package font by `scripts/subset-material-symbols.py`; do not replace it with a hand-edited binary.

Geist and Geist Mono come from the npm `geist` package and are distributed under the SIL Open Font
License 1.1. The full dependency license texts remain available in the installed npm packages; a
consolidated in-app third-party notices surface is still required before release.
